## 📌 Project Overview

This project was completed as part of my **Level 3 Data Technician Bootcamp with Leep Talent**.

I used **Microsoft Power BI** to clean, transform, analyse and visualise retail and sales datasets, turning raw business data into interactive reports and dashboards.

The project provided hands-on experience in **Power Query, DAX, data modelling, interactive reporting and data storytelling**, with a focus on understanding sales performance and supporting business decisions.

### 🧮 2. DAX Calculations

Used **Data Analysis Expressions (DAX)** to create calculated columns and measures for business reporting.

| DAX Function | Application |
|--------------|-------------|
| `SUM()` | Calculate total sales revenue |
| `AVERAGE()` | Calculate average sales |
| `COUNTROWS()` | Count transaction records |
| `CALCULATE()` | Apply filters to calculations |
| `DIVIDE()` | Calculate ratios safely |
| `IF()` | Create conditional calculations |
| `YEAR()` | Extract years from dates |
| `MONTH()` | Analyse monthly sales |

**Example DAX Measures:**
<img width="788" height="370" alt="image" src="https://github.com/user-attachments/assets/dcade9fb-f740-490a-a84f-2dc048561ab3" />


```dax
Total Sales = SUM(Sales[SalesAmount])

Total Transactions = COUNTROWS(Sales)

Average Sales = AVERAGE(Sales[SalesAmount])

Average Transaction Value =
DIVIDE([Total Sales], [Total Transactions])
```

*Note: These are illustrative DAX examples. Table and column names may differ from the actual project.*

## 💡 Data Storytelling & Business Insights

A key focus of this project was communicating analytical findings through clear and interactive visualisations.

The reporting process followed five stages:

1. **Prepare:** Clean and transform raw data using Power Query.
2. **Analyse:** Create DAX measures and explore relationships.
3. **Visualise:** Build charts, KPIs and interactive reports.
4. **Interpret:** Identify trends, patterns and differences.
5. **Communicate:** Present findings to support business decisions.

The aim was to make retail and sales information easier to understand and explore, allowing users to move from high-level performance summaries to more detailed analysis.
